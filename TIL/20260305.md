## 3) Terraform workspace

![image.png](attachment:ebb928cb-862e-410b-b859-44c8d08e9e2d:image.png)

```bash
# 워크스페이스 생성
terraform workspace new [name]

# 워크스페이스 리스크 출력
terraform workspace list

# 현재 워크스페이스 출력
terraform workspace show

# 워크스페이스 선택
terraform workspace select [name]

# 워크스페이스 삭제 (현재 워크스페이스는 불가)
# terrform destroy 안하면 리소스 남아있음
terraform workspace delete [name]
```
