## 1) Terraform Modules

- 인프라 코드를 재사용 단위로 묶은것
- 구조
  ```bash
  modules/
  └── vpc/
      ├── main.tf       # 리소스 정의
      ├── variables.tf  # 입력 변수
      └── outputs.tf    # 출력 값
  ```
- 예시
  ```bash
  # main.tf (루트)
  module "vpc" {
    source   = "./modules/vpc"   # 모듈 경로
    vpc_cidr = "100.0.0.0/16"
    region   = "ap-northeast-2"
  }
  ```

## 2) Ansible

- 앤서블 타워 (Ansible Automation P)
- 설치
  ```bash
  # 시스템 업데이트 및 PPA 추가
  sudo apt update
  sudo apt install software-properties-common -y
  sudo add-apt-repository --yes --update ppa:ansible/ansible

  # Ansible 설치
  sudo apt install ansible -y

  # 설치 확인
  ansible --version
  ```
- key pair 다른 서버로 복사 (리눅스 명령어)
  ```bash
  # 전송하는 서버에 입력
  scp -i "your-key.pem" your-key.pem ubuntu@<Master-IP>:/home/ubuntu/.ssh/

  # 복사 받은 서버에 입력
  # 권한 설정
  chmod 400 ~/.ssh/your-key.pem
  ```
- 호스트 서버에 워커 서버와 키페어 등록
  ```bash
  # /etc/ansible/hosts 맨아래 호스트 그룹과 변수입력

  [workers]
  worker1 ansible_host=172.31.x.x
  worker2 ansible_host=172.31.y.y

  [all:vars]
  ansible_user=ubuntu
  ansible_ssh_private_key_file=/home/ubuntu/.ssh/your-key.pem
  ```
- Ad-Hoc 명령어
  ```bash
  # 키페어를 최소 1번 이상 교환된 상태여야함.
  ssh -i your-key.pem ubuntu@privateIPv4(172.31.x.x))

  # 핑 테스트
  ansible workers -m ping

  # 서버 가동 시간 (uptime) 확인
  ansible workers -a "uptime"

  # 메모리 사용량 확인
  ansible workers -a "free -h"

  # 디스크 용량 확인
  ansible workers -a "df -h"
  ```
- 실습) install-docker.yml 파일 작성
  ```bash
  - name: Install Docker on Workers
    hosts: workers
    become: true

    tasks:

      - name: Install prerequisite packages
        apt:
          name:
            - ca-certificates
            - curl
            - gnupg
          state: present
          update_cache: yes

      - name: Create keyrings directory
        file:
          path: /etc/apt/keyrings
          state: directory
          mode: '0755'

      - name: Add Docker GPG key
        get_url:
          url: https://download.docker.com/linux/ubuntu/gpg
          dest: /etc/apt/keyrings/docker.asc
          mode: '0644'

      - name: Add Docker repository
        apt_repository:
          repo: "deb [arch=amd64 signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu {{ ansible_distribution_release }} stable"
          state: present

      - name: Install Docker Engine
        apt:
          name:
            - docker-ce
            - docker-ce-cli
            - containerd.io
            - docker-compose-plugin
          state: latest
          update_cache: yes

  - name: Deploy Nginx Container
    hosts: workers
    become: true

    tasks:
      - name: Run Nginx
        community.docker.docker_container:
          name: my-web
          image: nginx:latest
          published_ports:
            - "8080:80"
          state: started
  ```
  ```bash
  # playbook 위치에서 실행
  ansible-playbook install-docker.yml
  ```
