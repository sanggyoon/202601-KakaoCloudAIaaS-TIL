## 1) 복습

- ECR
  - Docker 설치
  - AWS cli 설치
  - AWS 콘솔에서 ECR repo 생성
  - Docker에 있는 이미지 푸시
- ECS
  - 클러스터 생성
  - 태스크 정의
  - 서비스 생성
- EKS
  - kubernetes 설치 (k8s, k3s, minikube 중 택)
  - hostname 변경
  - 마스터 노드, 워커 노드 등록
  - EKS pod 생성
  - 워커 노드에서 ECR 이미지 pull
  - pod 실행
- Github Actions
  - github repo 생성
  - git init, remote
  - 환경 변수 등록
  - .github/workflow 안에 .yaml 파일 생성
  - git push
