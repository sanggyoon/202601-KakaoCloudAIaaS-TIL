## 목차

1. aws-cost-cli 설치

## 1) aws-cost-cli

```bash
# node.js lts 버전 설치
npm install --lts

# aws-cost-cli 설치
npm install -g aws-cost-cli

# aws 자격 증명(Access key를 받아서 메모리에 저장)
export key=<AWS access_key>
export secret=<AWS secret_access_key>
export region=<AWS REGION>

aws-cost -k $key -s $secret -r $region

# 서비스 비용 출력 (+옵션)
aws-cost
aws-cost summary
aws-cost --text
aws-cost --json

# 선택) 슬랙 통합
aws-cost --slack-token [token] --slack-channel [channel]
```

- AWS Cost Explorer API를 사용
  - AWS Cost Explorer API는 요청 1회당 0.01USD 비용 발생

## 2) AWS ECS (Elastic Container Service)

- 완전관리형 컨테이너 오케스트레이션 서비스
- 이미지를 실행, 확장, 복구, 배포까지 관리
- 구성 요소
  - cluster
    - 논리적 그룹
    - 컨테이너를 실행할 인프라 풀
  - task definition
    - Json으로 작성, 콘솔 설정 가능
    - 이미지, 리소스, 환경변수, IAM 정의
  - task
    - 실행 인스턴스
    - 실제 동작하는 컨테이너 단위
  - service
    - task 수를 유지하는 역할
    - Auto Scailing, ALB연동, Rolling Update
- 실행 방식
  - ec2 launch type
    - ECS 클러스터가 EC2위에서 동작
    - 사용자가 직접 EC2를 프로비저닝
  - fargate launch type
    - ec2 인스턴스의 프로비저닝, 스케일링 관리 불필요
    - 서버리스 환경 (호스트 X)
    - task 단위로 cpu/memory 지정 필요
    - VPC, ELB, IAM, Cloud Watch와 연계
- 네트워킹 구조
  ```bash
  ALB
  ↓
  ECS Service
  ↓
  Task (awsvpc)
  ↓
  RDS / ElastiCache
  ```
- 많이 사용하는 구조
  ```bash
  Route53
  ↓
  ALB
  ↓
  ECS Service (Fargate)
  ↓
  ECR Image
  ↓
  RDS / ElastiCache
  ```
