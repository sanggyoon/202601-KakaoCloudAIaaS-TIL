## ⭐️ OSI 7계층

1. 물리
   - 비트 (ex. 0100100101011)
   - 리피터, 허브, 케이블
   - 물리적 장치의 전기 신호
2. 데이터링크
   - 프레임
   - 스위치, 브릿지
   - 데이터, TCP헤더, IP헤더, MAC주소
   - 정보의 오류와 흐름을 제어 (흐름 제어, 오류 제어, 순서 제어)
   - MAC 주소로 통신
   - Ethernet, ARP
3. 네트워크
   - 패킷
   - 라우터
   - 데이터, TCP헤더, IP헤더
   - 목적지인 경로(route)와 주소(IP)를 정하고 패킷을 전달
   - IP 주소로 통신
4. 전송
   - 세그먼트
   - 데이터, TCP헤더
   - TCP, UDP
     - TCP 연결 요청: 3-way handshake
       - Client → Server - SYN: 연결 요청
       - Server → Client - ACK + SYN: 확인 응답, 연결 요청
       - Client → Server - ACK: 확인 응답
     - TCP 연결 종료 요청: 4-way handshake
       - Client → Server - FIN: 종료 요청
       - Server → Client - ACK: 확인 응답
       - Server → Client - FIN: 종료 요청
       - Client → Server - ACK: 확인 응답
   - Port번호 사용
   - 오류 검출 및 복구, 흐름 제어, 중복 검사
5. 세션
   - 데이터
   - TCP/IP 세션 생성, 제거
6. 표현
   - 데이터
   - 표현방식 결정 (암호화, 압축, 변환)
   - TLS, SSL
7. 응용
   - 데이터
   - HTTP, HTTPS, FTP, SSH, DNS, SMTP

## VPC

- Route Table
  - 라우팅이 여러 개 있는 경우 트래픽과 일치하는 가장 구체적인 라우팅을 사용하여 트래픽의 라우팅 방법을 결정 → 10.10.0.0/16 보단 10.10.0.0/24가 더 구체적인 라우팅
- Security Group
  - 구성
    - 인바운드: 소스IP / 포트 / 프로토콜
    - 아웃바운드: 타겟IP / 포트 / 프로토콜
  - Stateful (응답 트래픽 자동 허용) 인바운드 요청을 허용하는 룰이 설정된 경우, 해당 요청에 대한 응답 트래픽은 자동으로 아웃바운드 방향으로 허용
  - 인바운드, 아웃바운드 IP주소 위치에 보안그룹이 대신 들어갈 수 있다.
    - 이때 ALL @default ALL의 의미는 같은 default 보안그룹에 속한 모든 트래픽을 허용한다는 의미. 그룹이 다르면 허용 안 함.

## IPv4 주소 범위

**클래스별 범위**

| 클래스 | 범위                        | 용도          |
| ------ | --------------------------- | ------------- |
| A      | 0.0.0.0 ~ 127.255.255.255   | 대형 네트워크 |
| B      | 128.0.0.0 ~ 191.255.255.255 | 중형 네트워크 |
| C      | 192.0.0.0 ~ 223.255.255.255 | 소형 네트워크 |
| D      | 224.0.0.0 ~ 239.255.255.255 | 멀티캐스트    |
| E      | 240.0.0.0 ~ 255.255.255.255 | 예약(실험용)  |

**사설(Private) IP 범위**

- `10.0.0.0 ~ 10.255.255.255` (/8)
- `172.16.0.0 ~ 172.31.255.255` (/12)
- `192.168.0.0 ~ 192.168.255.255` (/16)

**특수 주소**

- `127.0.0.1` — 루프백(localhost)
- `169.254.x.x` — APIPA (자동 링크-로컬)
- `0.0.0.0` — 모든 인터페이스
- `255.255.255.255` — 브로드캐스트
