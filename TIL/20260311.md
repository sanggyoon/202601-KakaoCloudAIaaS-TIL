## 1) Ansible Semaphore

- Ansible을 GUI로 실행/관리하는 툴
- 설치 (ec2-ubuntu)
  ```bash
  # 1. 설치
  cd ~
  wget https://github.com/ansible-semaphore/semaphore/releases/download/v2.9.45/semaphore_2.9.45_linux_amd64.deb
  sudo dpkg -i semaphore_2.9.45_linux_amd64.deb

  # 2. 초기 설정
  semaphore setup
  # - DB: 2 (BoltDB)
  # - 나머지 기본값 Enter
  # - 사용자 계정 생성

  # 3. systemd 서비스 등록
  sudo tee /etc/systemd/system/semaphore.service << EOF
  [Unit]
  Description=Semaphore Ansible
  Wants=network-online.target
  After=network-online.target

  [Service]
  Type=simple
  ExecStart=/usr/bin/semaphore server --config=/home/ubuntu/config.json
  SyslogIdentifier=semaphore
  Restart=always
  RestartSec=10s

  [Install]
  WantedBy=multi-user.target
  EOF

  # 4. 서비스 시작
  sudo systemctl daemon-reload
  sudo systemctl enable --now semaphore

  # 5. 접속 URL 확인
  echo "http://$(curl -s ipinfo.io/ip):3000"
  ```
