## 1) AWS Fargate

- 특징
  - AWS Fargate 는 컨테이너 전용 서버리스 런타임
  - EC2 인스턴스를 프로비저닝하거나 관리하지 않음
  - Task 단위로 CPU/Memory를 지정해 실행
  - 강한 격리 구조, 보안에 강함
  - 사용량에 따라 ec2가 저렴할 수 있음
- 내부 동작 구조
  1. ECS Service가 Task 요청
  2. AWS가 내부적으로 격리된 실행 환경 생성
  3. ENI(Elastic Network Interface) 할당
  4. ECR에서 이미지 pull
  5. 컨테이너 실행
- 네트워크 구조와 특징
  - Fargate는 항상 awsvpc 네트워크 모드 사용.
  - Task마다 전용 ENI
  - 고유 Private IP
  - 보안 그룹 직접 적용 가능
  - VPC/Subnet 필수

## 2) Container → AutoScaling 실습

- 컨테이너 이미지 생성
- ECR에 이미지 등록
- ECS 생성
  - VPC 생성
  - 클러스터 생성
  - 테스크 정의 작성
  - 서비스 생성
- 자동 복구
- 스케일 변경
