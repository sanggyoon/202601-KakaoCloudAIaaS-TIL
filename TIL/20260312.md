## 2) ncloud cli 설치

```bash
# java 설치
apt install -y default-jre

# cli 다운로드 및 파일 이동
wget https://www.ncloud.com/api/support/download/files/cli/CLI_1.1.27_20251120.zip
unzip CLI_1.1.27_20251120.zip
mv CLI_1.1.27_20251120/cli_linux /opt/ncloud

# 스크립트 절대 경로 수정
cat > /opt/ncloud/ncloud << 'EOF'
#!/bin/bash
/opt/ncloud/jre8/bin/java -jar /opt/ncloud/lib/ncloud-api-cli-1.1.27-SNAPSHOT-jar-with-dependencies.jar "$@"
EOF

# PATH 등록
echo 'export PATH=$PATH:/opt/ncloud' >> ~/.bashrc
source ~/.bashrc

# 인증키 설정
ncloud configure

# 동작 확인
ncloud vserver getRegionList
```
