## 1) Ansible

- 기본 명령어
  - 명령 옵션
    - -m : 모듈 선택 (생략시 기본 모듈 command)
    - -a : 옵션, 명령어 인자
  - 모든 워커에 디렉토리 생성
    ```bash
    ansible workers -m file -a "path=/home/ubuntu/my_project state=directory"
    ```
  - 로컬 파일을 모든 워커로 전송
    ```bash
    ansible workers -m copy -a "src=~/local_file.txt dest=/home/ubuntu/test.sh"
    ```

    - 쉘 스크립트 작성 후 워커들에게 전송
    - `ansible workers -a “sudo chmod +x test.sh”` 로 실행 권한 부여
    - `ansible workers -a “./test.sh”` 로 워커 내에서 실행
  - 모든 워커에서 파일 삭제
    ```bash
    ansible workers -m file -a "path=~/test.sh state=absent"
    ```
- Inventory
- Playbook
  - playbook 작성법
    ```bash
    - hosts: workers        # inventory 그룹명
      become: yes           # sudo 권한
      tasks:
        - name: 작업 설명   # 로그에 표시되는 이름
          모듈:
            옵션: 값
    ```
  - playbook 실행
    ```bash
    # 기본 inventory(etc/ansible/hotsts 사용)
    ansible-playbook playbook.yml

    # inventory 지정
    ansible-playbook playbook.yml -i inventory
    ```
